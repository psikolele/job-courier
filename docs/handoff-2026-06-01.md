## Architettura corrente (punti chiave per nuova sessione)

### Stack
- React + Vite + Tailwind + Framer Motion + GSAP + lucide-react
- Vercel serverless functions (`webapp/api/jobs.js`, `webapp/api/job-detail.js`)
- GitHub Actions: cron job aggiorna `latest_jobs.json` su branch `data`

### API jobs
- `GET /api/jobs` → scrape JobRoom (3 pagine × 15 = 45 job, BATCH_SIZE=3 parallelo)
- `GET /api/jobs?singlePage=1` → solo 1 pagina (15 job), ~3× più veloce
- `GET /api/job-detail?id={jobroom_id}` → dettaglio singolo annuncio (Cheerio scrape)
