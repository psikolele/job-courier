## Architettura corrente (punti chiave per nuova sessione)

### Stack
- React + Vite + Tailwind v4 + Framer Motion + GSAP + lucide-react
- Vercel serverless functions (`webapp/api/jobs.js`, `webapp/api/job-detail.js`)
- GitHub Actions: cron job aggiorna `latest_jobs.json` su branch `data`

### API jobs
- `GET /api/jobs` → scrape JobRoom (3 pagine × 15 = 45 job, BATCH_SIZE=3 parallelo)
- `GET /api/jobs?singlePage=1` → solo 1 pagina (15 job), ~3× più veloce
- `GET /api/job-detail?id={jobroom_id}` → dettaglio singolo annuncio (Cheerio scrape)

### DotCard CSS (index.css — classi .jc-dot-*)
```css
.jc-dot-outer  { width:100%, flex:1, height:160px, relative, flex-center }
.jc-dot-dot    { 6px circle fuchsia #FF1F7A, transform:translate(-50%,-50%), z-index:5 }
                 direction='cw' → jcMoveDot 4s | direction='ccw' → jcMoveDotCCW 4s
.jc-dot-card   { inset:0, glassmorphism, border-radius:12px }
.jc-dot-text   { Satoshi 900, 2.4rem (1.9rem se display>7 chars), #a8c4e8 }
.jc-dot-label  { Satoshi 700, 0.58rem, uppercase, letter-spacing:0.18em }
.jc-dot-line   { 1px lines ai 4 lati }

@keyframes jcMoveDot    { 0/100%→top:0 left:0 | 25%→top:0 left:100% | 50%→top:100% left:100% | 75%→top:100% left:0 }
@keyframes jcMoveDotCCW { speculare: 0/100%→top:0 left:100% | 25%→top:0 left:0 | 50%→top:100% left:0 | 75%→top:100% left:100% }
```
